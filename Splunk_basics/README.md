🎄 Advent of Cyber — Splunk Basics

A hands-on introduction to SIEM analysis using Splunk (TryHackMe Event)

This repository documents my notes, screenshots, and learning progress from the Splunk Basics challenge in the Advent of Cyber event hosted by TryHackMe.
The task introduced SIEM fundamentals, log searching, detection techniques, and how security analysts use Splunk to investigate incidents.

🔍 What is Splunk?

Splunk is a Security Information and Event Management (SIEM) tool used by cybersecurity analysts to:

Collect massive amounts of logs

Search, filter, and visualize security events

Detect malicious activities inside a network

Investigate incidents and breaches

In Advent of Cyber, Splunk is used to solve real investigation challenges.

🎯 Learning Objectives

🟦 1. Work with SPL (Search Processing Language)
